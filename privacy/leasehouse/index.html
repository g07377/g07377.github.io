01 適用範圍與聯絡

本政策適用於 Android 應用程式「租屋管家」（LeaseHouse），套件名稱為 life.nistudio.leasehouse，由 Natural Intelligence Studio 提供，主要服務台灣使用者。

隱私與支援聯絡信箱：testfornewin1@gmail.com

如對資料處理、查閱、更正、停止使用或刪除方式有疑問，可來信詢問。來信內容會由我們使用的電子郵件服務處理，用於回應你的請求。請勿寄送不必要的身分證件、完整租約、帳戶資料或其他敏感內容。

02 App 處理哪些資料

租屋功能的內容主要由你自行輸入、拍攝、選取或操作產生，可能包含：

  • 住所與租約：住所名稱、地址、搬入搬出日期、租期、租金、押金、房東及管理人員聯絡資料、備註。
  • 帳務與分攤：固定費用、帳單、付款與退款、金額更正、押金異動、水電讀數與計價依據、室友姓名與聯絡備註、分攤及還款紀錄。
  • 生活與文件紀錄：點交清單、報修事件與聯絡紀錄、照片、PDF、收據、報告、搬家事項、租屋補助案件與提醒。
  • 設定及運作資訊：通知與顯示偏好、App 鎖設定、PIN 驗證資料、紀錄識別碼、時間、刪除標記、檔案完整性檢核資訊，以及保存在本機的廣告導覽計數。
  • 廣告相關資料：Google 廣告服務處理的 IP 位址、裝置或其他識別碼、互動與診斷資料，詳見第 07 節。

你輸入的內容或選取的附件可能含有你或他人的個人資訊。請只保存與租屋管理有關、且你有權使用的資料。App 不會自動讀取你的通訊錄、簡訊、行事曆或銀行帳戶，也沒有 GPS 定位功能。

03 資料用途與保存位置

租屋內容用於整理住所與租約、計算與核對費用、分攤記帳、保存證據與文件、建立提醒，以及執行你要求的匯入、匯出、備份與還原。

核心紀錄保存在手機上的 SQLCipher 加密資料庫；附件保存在 App 私有空間並以 AES-GCM 加密。金鑰由 Android Keystore 相關機制保護。設定保存在本機，並非所有偏好或臨時顯示資料都採用與資料庫相同的加密方式。

App 不提供開發者帳號伺服器或自動同步租屋內容的服務，不會把租約、地址、金額、照片或文件內容作為自訂廣告定向參數傳給 Google。廣告與 UMP 服務的網路處理另依第 07 節說明。

App 設定停用 Android 自動備份，並在備份規則中排除雲端備份與裝置轉移。請自行建立所需備份。裝置遺失、故障、清除資料或解除安裝可能使本機紀錄無法復原；加密也不能保證消除所有安全風險。

04 匯出、分享與備份

只有當你啟動相關操作時，App 才會透過 Android 系統選檔器或分享功能，將指定檔案交給你選擇的目的地或接收 App。目的地可能是手機儲存空間、Google Drive 或其他已安裝的文件服務；該服務依自己的政策處理傳輸、存取與保存。

  • 加密備份：.lhb 備份以你設定的密碼加密，可包含租屋紀錄、設定、所需附件及部分刪除歷史；不等同只匯出畫面上目前可見的內容。請保管密碼與備份檔。
  • 文件、報告及資料包：PDF、照片、CSV 或其他匯出內容可能是可直接讀取的明文。分享前請檢查檔案與接收對象。
  • 分享副本：部分報告提供省略住所、聯絡資料、備註或照片等選項。遮蔽規則不能保證辨識出所有文字或圖片中的個人資訊，仍請自行檢查。
  • 圖片中繼資料：一般匯入或隱私分享流程會重新編碼圖片；若選擇保留或分享原始檔，原始檔可能仍含位置、拍攝時間等中繼資料。PDF 與圖片畫面本身也可能含有個人資訊。

為預覽、拍照、匯出或分享，App 可能在私有暫存區產生明文副本。清理流程會在執行時移除超過約一天的相關暫存檔，並非每份檔案在使用後立即刪除。接收 App 已取得的副本不受此清理影響。

05 資料保留與刪除

租屋紀錄沒有統一的固定天數自動刪除期限。封存、刪除與清除全部資料的效果不同：

  • 封存與一般刪除：為保留帳務、關聯與復原資訊，部分紀錄使用軟刪除或保留歷史，不會在介面消失時立刻從儲存空間完全清除。
  • 文件回收區：不再被引用且刪除已超過 30 天的附件，可在清理流程執行時移除檔案；識別碼、刪除狀態及相關歷史仍可能保留。清理時間也受 App 執行及系統排程影響。
  • 全資料刪除：可在「我的家 → 設定 → 全資料刪除」清除 App 內紀錄、附件及相關本機設定。也可使用 Android 的清除儲存空間或解除安裝功能。這些操作不可用來取回未備份的資料。
  • 外部副本：本機刪除不會刪除你已匯出、分享、寄送或保存至雲端的檔案。請另外在相關 App、裝置或雲端服務中刪除，並留意其垃圾桶與保留規則。

開發者沒有可替你查閱、復原或遠端刪除手機租屋資料的帳號後台。還原舊備份可能重新帶回備份當時的紀錄。Google 保存的廣告資料由 Google 的保留規則與控制機制處理；清除本機資料或重設廣告識別碼不保證同步刪除已由 Google 保存的資料。聯絡信件依處理請求及適用義務所需保留。

06 系統權限與裝置功能

  • 相機：在你選擇拍照時擷取點交、報修、抄表或其他附件。
  • 照片與檔案：透過系統選取器存取你選擇的內容，或將匯出檔案寫入你選擇的位置，不要求全面讀取整個照片庫。
  • 通知與背景排程：用於帳單、租約、報修、搬家或自訂提醒；提醒內容可能出現在鎖定畫面，請依需要調整 Android 通知設定。
  • 生物辨識：選用的 App 鎖交由 Android 系統驗證，App 不取得你的指紋或臉部生物辨識範本。
  • 網路及廣告識別：用於廣告載入、隱私訊息與第三方網頁。網路可傳送 IP 等連線資訊，即使未授予定位權限，也可能被用來推估概略位置。

你可透過 App 或 Android 設定調整適用的選項與權限。拒絕某項權限可能使對應功能無法運作，不會自動刪除之前保存的資料。

07 Google AdMob 與隱私選擇

App 整合 Google Mobile Ads Next-Gen SDK，提供橫幅、原生與插頁廣告，並使用 Google User Messaging Platform（UMP）處理適用的隱私訊息與同意狀態。

Google SDK 會為廣告、分析與防詐目的自動收集及分享資料，包括：

  • IP 位址，以及由 IP 推估的概略位置。
  • App 與廣告互動，例如啟動、點擊或影片觀看。
  • 效能與診斷資訊，例如啟動時間、停滯率與耗電情形。
  • 裝置、App 或帳戶相關識別碼，例如廣告 ID、App Set ID，以及依設定和裝置狀況可用的其他識別碼。

資料可能在沒有點擊廣告時就進行處理。依 Google 的 SDK 說明，其收集的使用者資料在傳輸途中使用 TLS 加密。實際可用資料與廣告形式依地區、SDK 設定、裝置控制及隱私選擇而異。

管理你的選擇

UMP 會向 Google 更新同意資訊；App 依 UMP 的可請求廣告狀態控制 SDK 初始化與廣告請求。當 UMP 判定需要提供隱私選項入口時，可從「我的家 → 設定 → 廣告隱私選項」重新開啟表單。此入口與表單並非所有地區或使用者都會顯示。

Android 設定可能提供重設或刪除廣告識別碼的功能。非個人化或有限廣告仍可能涉及資料處理，並不代表完全不收集資料。Google 的處理方式及其他控制選項請參考：

08 外部網站與政策託管

App 提供的官方資源連結會開啟第三方網站；你在該網站輸入的資料由該網站處理。租屋管家不是政府機關，也不代表政府受理租屋補助、申訴或其他案件；App 內的案件追蹤與提醒不等同向主管機關提出申請。

本政策頁面託管於 GitHub Pages。GitHub 可能處理訪客 IP 位址與請求資訊，以提供及保護網站服務。本頁本身沒有廣告、分析追蹤程式、第三方字型或資料輸入表單。
